# docs-nemo-waves

Website Brief Phase 0 của Nemo Waves. Tài liệu đang ở trạng thái **draft**, chưa được nhập vào kho `docs/` canonical của Nemo12.

## Chạy tại máy

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Nguồn nội dung website nằm trong `docs/`. Khi Brief được Nemo12 duyệt và đưa vào hệ tài liệu canonical, website này cần trỏ về nguồn đó để tránh hai bản song song.
